# Homepage banners

`quantum-materials-banner-v1.jpg` is AI-generated conceptual research imagery, created with the built-in ImageGen tool on 2026-10-26. It depicts a plausible quantum-materials chip, sample holder and low-temperature measurement hardware. It does not document the author's laboratory or a measured result.

The image was converted to JPEG for web delivery without changing its composition. The shallow homepage crop is controlled by CSS, so the original 3:1 composition remains available in the asset. The exact generation prompt is saved in `research-banner.prompt.txt`.

Banner source, alternative text and visibility are configured by `home_banner` in `data/profile.json`.

`quantum-materials-banner-v2.jpg` is a second AI-generated conceptual photograph, created with the built-in ImageGen tool on 2026-10-26 for the optional slideshow. It evokes graphene nanostructures, scanning gate microscopy and quantum transport using a chip, gold contacts and a scanning probe. It is illustrative imagery rather than a photograph of the author's laboratory or research data. The exact prompt is saved in `research-banner-v2.prompt.txt`.

Both images retain their original 2172 × 724 composition. The site displays a shallow crop. Select a fixed image or a slideshow through `home_banner.mode` in `data/profile.json`.
